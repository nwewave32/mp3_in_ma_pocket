## 🎯 요청 / 배경

Mac이나 '파일' 앱으로 넣은 파일이 앱을 다시 열 때 목록에 나타나야 했다(F2). 또 기기에서 실행해 보니 지운 곡이 다음 가져오기 때 다시 나타나서, 삭제가 실제 파일까지 지우도록 고쳐야 했다(F5).

## 🔧 한 일

- `lib/app/library_controller.dart` 새로 작성
  - `LibraryController extends ChangeNotifier`: 곡 목록 상태를 `design_preview.dart`에서 이쪽으로 옮겼다.
  - `refresh()`: `_generation` 카운터를 두어 가장 최근에 시작한 폴더 읽기 결과만 반영한다. 삭제 전에 시작한 읽기가 늦게 끝나도 지운 곡이 되살아나지 않는다.
  - `import()`: `_importing`으로 중복 실행을 막는다.
  - `delete(track)`: 파일을 지운 뒤 다시 읽는다.

## 🧩 이슈 · 해결

- 지운 곡이 가져오기 후 다시 나타났다. 원인은 삭제가 메모리 목록에서만 빠지고 파일은 남아 있었기 때문이다. `Mp3Library.delete()`로 실제 파일을 지우도록 고쳤다.
- 테스트 중 `withRealIo` 안에서 위젯을 띄우면 `PreviewPlayer` 타이머가 실제 시간으로 돌아 진행 시간 테스트가 깨졌다. `pumpWidget`과 `settleIo`를 따로 쓰고, 폴더 목록을 읽을 때 가짜 시계를 `pump(1ms)`로 앞으로 돌리도록 바꿨다.
